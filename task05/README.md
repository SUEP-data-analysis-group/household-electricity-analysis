## 仍需完成的预处理

1. 主贡献表只比较同一固定面板、同一组所有设备共同有效的时间。不能让不同电器各用各的有效日期，再把电量直接排名或相除。
2. 设备全期或月度电量占比用共同合格区间内的设备电量除以同区间面板电量。“全期”需明确是全部观测期间的有效样本，而非已补齐全年；分母为 0 时占比不可定义。
3. 主面板若锁定 13 台，主表只解释这 13 台。电饭煲作为补充，使用 14 台共同有效的独立子区间，并同步重算该区间全部设备占比。不能把该电饭煲占比塞进全年 13 台排序。
4. 任务四的小时峰时贡献，按同一小时内各设备平均功率计算；若分析分钟峰时贡献，另行明确是哪一分钟。两个贡献口径分别展示。
5. 运行状态由设备特性、待机功率及观测情况确定，建议使用开机与关机不同阈值、最短持续时间抑制抖动，冰箱和空调需区分压缩机运行与通电。阈值逐设备记录，不采用统一“功率大于 0 即运行”。
6. 缺测分钟运行状态为 unknown，不能当作关闭。重叠频率的分母为所比较设备全部状态已知的分钟数；高缺测设备不能与完整设备用不同分母直接比较。
7. 保留分钟级重叠信息。只用小时平均功率无法判断两台电器是在同一分钟运行还是先后运行。堆叠图遇缺口应断开或标缺测，不用 0 补齐图面。
8. 行为变量只能按照其原始语义解释，运动检测为 0 不能作为无人证据。天气或行为与用电同时变化只能支持关联，不能单凭相关性断言因果。
