## 字段口径：后续任务必须按这里读取

- `energy_kwh`：完整时段电量。小时要求 60/60 面板联合有效分钟；日要求 24/24 合格小时，不完整时段为空。
- `mean_power_kw`：严格平均负荷。完整一小时内数值等于 energy_kwh；不完整小时为空。完整日平均负荷为日电量 / 24h。
- `valid_duration_energy_kwh`：仅累加有效分钟的电量，全缺失时为空；不能称完整时段电量，不按覆盖率放大。
- `observed_duration_mean_power_kw`：小时表中对有效分钟片段的均值，仅供诊断。后续预测不得将它充当完整小时真实目标。
- `hour_complete/day_complete`：下游仍须显式使用质量标记，不能删除缺测后压缩时间轴。
- `hourly_appliance.csv` 保留每设备自身有效性。贡献比较须再与同一面板共同合格时段匹配，不能让各设备使用不同日期计算占比。

功率为 W，分钟近似积分为 sum(P_W)/60000 kWh；小时标签为区间起点、左闭右开。源序列已由作者规则化并含上游保持/填补，不能称逐点原始实测。标准表首尾的 2022-06-01 00:00 单条不进入本次聚合。

## 月度和季节样本

主分析区间 `[2021-05-31,2022-06-01)`，366 个自然日，8503 个完整小时、352 个完整日。完整日合计 2739.597137 kWh，日均 7.782946 kWh，最高 2021-07-15、最低 2022-01-28。

2021-05 只有 1 日，2021-06/07 分别有 21/26 个完整日，不能报告完整月电量；2021-08 至 2022-05 共 10 个完整月。月度曲线仍保留样本支持，n=1 的月份不代表整月规律。

气象季节为 3–5 春、6–8 夏、9–11 秋、12–2 冬。`season_period` 用十二月所在年份命名冬季，并分开两端春季：2021_spring 1 日、2021_summer 78 日、2021_autumn 91 日、2021_winter 90 日、2022_spring 92 日。每期 24 小时使用同一组日期，阴影为 25–75 分位范围，不是均值置信区间。

## 复现与核验

完整主项目根目录中：

```powershell
python -m pip install -r task02/requirements.txt
python task02/run_task02.py
python task02/verify_task02.py
```

桌面独立 task02 成果包不附带体积较大的标准原件；在该成果包根目录中显式指向本地 task01 主项目：

```powershell
python task02/run_task02.py --source-root 'D:\Desktop\家庭用电分析方案'
python task02/verify_task02.py --source-root 'D:\Desktop\家庭用电分析方案'
```

`--source-root` 只改变读取标准数据/任务一核验表的位置，输出仍写入本成果包。普通运行会重新生成派生表和图；验证程序只写核验日志。程序遇到缺少必要设备质量文件会报错，不静默省略设备。

清单保留生成时的历史绝对路径；核验器会将标准数据和 task01 参考表映射到当前根目录或显式指定的 `--source-root`，仍检查相同 SHA-256。克隆到其他盘符无需创建原来的桌面目录。
